## 本阶段交付

- 增加中国召回专用查询、列表、公告、资源引用、访问依据、结果和原件共享 DTO。检索页保留数字页码、声明总数及导航限制，查询页码沿服务端合同使用字符串。
- SDK 增加 `samrRecallQuery`、`samrRecallHistory`、`samrRecallEvidence`，传递取消信号、单次授权及显式历史模式。
- 从工作台来源页及命令面板进入召回窗口，选择“中国市场监管召回”，可检索、翻页、读取公告、重开官方原文及保存的原始证据。
- 页面分别展示原显示发布日期、规范日期、DeployTime、PubDate、核验时间和快照观察时间。公告正文与 HTML／JSON 原件通过既有 DataTree 展示纯文本，图片和附件继续显示获取状态。
- 接通单次允许／拒绝以及检索页、公告两类持续回退。拒绝后清除对应的等待结果。关键字、查询方式、来源代次和卸载均可使旧请求失效。

## 原始失败及复核

1. Chrome MCP 共享配置目录被其他实例占用。只读确认归属后，本阶段改用独立无代理浏览器，经本地 CDP 验收。
2. 首批私有启动脚本从仓库根目录启动 Next，配置导入失败。按正常 Web workspace 的工作目录启动后通过，原错误日志保留。
3. 首批 23 项流程通过后，代码复核发现拒绝授权仍显示等待文字。本次修正拒绝分支清除对应结果，最终流程核对等待文字和授权按钮均消失。
4. 扩展私有 QA 将持续策略的 `article` 元素计作公告结果，导致取消断言失败。原始 DOM 显示结果已清空，后续断言定位实际 `.recall-product`，最终同一取消流程通过。
5. 首次关闭探针把自身命令行计作残留进程。最终探针限定实际启动的进程 ID 及 Chrome／Node／Python 名称，保留两次关闭记录。

上述失败各自保留回执。后端阶段记录的间歇 Parser 超时继续待查。
