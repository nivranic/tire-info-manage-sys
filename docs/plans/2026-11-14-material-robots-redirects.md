# 许可材料 robots 跳转与专业原件留存计划

基线为 `5a56421`。本阶段推进原规格中的专业测试原件、出处与可恢复引用。使用现有管理员策略、捕获接口和对象存储。[原规格](../requirements/2026-09-26-tire-intelligence-original.md)

## 已观察的阻点

《Ultra Low Noise Poroelastic Road Surfaces》，DOI `10.3390/coatings6020018`，出版页声明 CC BY 4.0。三次正常捕获分别记录出版站 robots 403、出版方 CDN robots 301 和学术仓储 robots 301。后者指向固定 HTTPS 404 页面，同仓储 PDF 的 HEAD 为 200、application/pdf、6136722 字节。原始回执位于 Git 忽略的独立材料工作区。

## 实施

1. `material_source_policy.py` 增加可选 `robots_redirect_urls` 精确 HTTPS 清单，最多 3 项。空清单在序列化时省略，保存既有策略与请求的指纹语义。
2. `material_source_transport.py` 逐跳检查声明地址、公网解析、TLS、循环和3跳上限。robots 200解析规则，404／410记录缺失，其他状态保留明确失败。成功记录原始robots地址、终点和每跳状态。
3. `source_materials.py` 验证新链路并使用 `source-material-receipt@2`，继续读取既有 @1。保存、重开和幂等重放均核对冻结策略、实际跳转及原件摘要。
4. 共享类型和 Web 展示策略声明的 robots 地址及实际链路，校验 @1／@2 与精确绑定。
5. 增加策略兼容、合法跳转、未知地址、HTTP 降级、循环、跳数、私网解析、状态、旧凭证和篡改回归，沿正式受管入口运行。
6. 经正常捕获接口留存真实仓储 PDF，核对作者、题名、DOI、出版许可、页码与表格，使用现有 PDF 解析／正文引用入口及实际页面重开。按实际材料保留参测对象身份、条件和来源差异。

## 验收

受管回归、全工作区类型、Web 构建及正常页面通过。真实材料只保存在 Git 忽略目录，出处包含实际仓储地址。既有失败请求与 KIT C2 封存记录独立保留。原件与传输验证、内容身份、精确 SKU、人工审核及真实 Provider 分别按实际证据记录，完整 V1 继续实施。

## 实测后的期限调整

三次真实PDF正文在既有20秒总期限内超时，其中分块观测记录分别收到6,069,978和2,768,154字节，响应声明完整大小6,136,722字节。独立材料捕获总期限据此调整为45秒，连接4秒、读取8秒、8MiB上限、并发2及逐host节流沿既有实现执行。正式回归继续验证总期限取消、会话关闭和容量释放。该调整覆盖R72初始计划中的20秒设置。
