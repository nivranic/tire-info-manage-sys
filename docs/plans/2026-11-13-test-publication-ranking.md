# 人工测试出版物角色与检索排序

## 依据与现状

原规格要求原始测试依据优先，保留来源与修订。首批真实检索评估发现，两份同场测试转录均使用manual_test，较晚录入的论文转述优先于原始媒体报道。宽查询的Agent标注nDCG@1为0.142857。

## 设计

事件payload增加可选publication声明，role取original_report、secondary_report或unknown，basis使用现有有界纯文本。声明随事件修订及指纹保存。序列化缺省和null声明时省略该字段，保持旧事件表示和指纹。事件历史、CAS、撤销及恢复复用既有链路。

知识投影携带声明和事件指纹，检索展示它们及原有精确事件修订引用。当本次候选均为测试事件时，在既有字段权威之后、文本／融合分数与录入时间之前采用出版物角色排序。候选含多类实体时沿用既有字段排序。未知角色使用同一级，原有词法与时间排序继续决定先后。

声明依据作为出处元信息保存，正文FTS及向量输入使用现有客观测试内容。旧投影通过索引版本升级重建。Web沿既有编辑／修订入口录入声明，详情和检索展示声明及其绑定。

操作者声明和Agent标注继续待外部真人核验。独立／委托关系、精确SKU及许可按照各自字段与流程验收。
